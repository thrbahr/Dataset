# Datasets for Semantic Labeling of Social Big Media

This repository provides the datasets used for the experimental evaluation in the following paper:

**A. Naeimi Sadigh, T. Bahraini, and H. Sadoghi Yazdi, "Semantic labeling of social big media using distributed online robust classification," Engineering Applications of Artificial Intelligence, vol. 132, 107928, 2024.**

DOI: https://doi.org/10.1016/j.engappai.2024.107928

The repository is provided to facilitate **reproducibility and further research** based on the experimental results reported in the paper.

The datasets include synthetic and real-world benchmark datasets used to evaluate the proposed distributed online robust classification method under different noise and outlier conditions. The real-world experiments include datasets from the **UCI Machine Learning Repository** as well as the **500px social media dataset**. For the image-based experiments, image samples are represented by feature vectors extracted using the AlexNet deep neural network.

For each dataset, the corresponding data files and, where available, the original source or download link are provided in this repository.
